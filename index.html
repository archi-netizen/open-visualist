Context-aware image sourcing
for the Public Domain.

Stop generating. Start discovering.

In an era of AI-hallucinated imagery, OpenVisualist prioritizes the provenance of the real. It reads a draft, understands what it's actually about, and sources genuine public-domain photography to match — for writers, historians and publishers who'd rather cite a source than fabricate one.

This is a live interface, not a screenshot — but it needs its own engine. The demo below talks directly to the OpenVisualist API over POST /analyze-and-source; nothing on this page is simulated. To see real results, clone the repository, run the API locally with uvicorn api.main:app --reload --port 8000, and point the API URL field below at it. Without that running, typing below will just show a connection error — that's expected, not broken.
